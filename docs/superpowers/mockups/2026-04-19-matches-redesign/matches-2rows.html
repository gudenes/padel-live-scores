What changes — precise

  • Dropped: the round/court meta-pill row (KHUFU · CC, CENTRE · MEN, COURT 2 · WOMEN) that used to sit above each pair of pairs. Round is already implied by the tournament header; gender is already encoded in the left accent bar.
  • Dropped: the separate Live · Set 2 chunky pill. The live set number now appears inline as a tiny Set 2 label adjacent to the live score column in brand red.
  • Dropped: the FINISHED pill on completed matches. Replaced by a terse FT label in the score column.
  • Kept: gender accent bar (blue men / purple women), dual-player overlapping flags, pair names, set-score column with current-set green highlight, per-point live red score, follow-star in row corner, tap target.
  • Row height: was roughly 96 px with meta row, now 64 px without — about a third more matches visible per screen.

If the direction lands, the V3MatchRow rewrite is local to src/app/[locale]/(app)/matches/page.tsx and will not touch anything else. Tell me if anything above is off — e.g., court label should stay, or FT pill is needed for results tab.
