v6 changes

  • Tournament header: country flag removed. Left column is now just the circuit logo (Premier Padel / FIP Tour) with its hairline separator. Right of it: City, Country on line 1, level pill + round on line 2. The header grid is 72px · 1fr · auto.
  • Variant A — dual country flags on each pair (unchanged from v5): 24×18 container, two 14×10 flags overlapping. Good when players are unknown or avatars are missing.
  • Variant B — dual player avatars. 34×22 container, two 22×22 circles overlapping by 10px. The ring around each avatar uses var(--bg-2) so the overlap reads cleanly. In production we'd wire in the existing <Avatar src={player.avatar_url} /> component; mockup uses initials on colored gradients as fallback mood.
  • Fallback plan for B: when avatar_url is null, show the player's initials on a deterministic colour derived from the player id — same pattern the rest of the app already uses for avatar-less players.
