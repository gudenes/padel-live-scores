Notes

Where it lives

Next to the EN VIVO filter pill in the matches-page filter bar. Same vertical row, same chunky-pill family — feels native to the existing UI.

When it shows

Only when at least one of Premier Padel YouTube or FIP Tour YouTube has a live broadcast right now. When neither is live, the pill is hidden entirely (no dead control).

The count badge

Tiny white-on-red number = how many channels are live. 1 when only one is broadcasting; 2 when both are. Communicates the size of the panel before opening it.

Tap to expand

Opens an inline panel below the filter bar — pushes the day's tournaments down. Each channel: logo + live stream title (when known) + VER CTA that opens YouTube. Tap the pill again or anywhere outside the panel to collapse.

Stream title fallback

If the stream title isn't parseable (e.g. generic "Premier Padel Live"), we still show the row but with just the channel name and a subdued "Open channel" subtitle — the YT pill never lies about live status, but the granularity degrades gracefully.
