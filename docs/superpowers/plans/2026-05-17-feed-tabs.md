# Feed Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the broken `<NewsRail>`-above-search-bar layout on `/[locale]/feed` with a four-tab interface (News default · Videos · Originals · Saved), reusing the existing chunky-tab pattern from PicksTabs.

**Architecture:** Server component (`page.tsx`) fetches first-party posts via `listPublished` and passes them as a prop to the existing client `FeedClient`. A new sibling `FeedTabs.tsx` renders the sticky tab row. Active tab lives in the URL (`?tab=`), read with `useSearchParams`, written with `router.replace`. Per-tab rendering filters the existing scored cluster output for News/Videos/Saved, and renders the new `originals` prop for Originals.

**Tech Stack:** Next.js 16 App Router, React 19, next-intl, Tailwind v4 inline styles (project convention), Supabase via existing `news-queries.ts`.

**Spec:** [docs/superpowers/specs/2026-05-17-feed-tabs-design.md](../specs/2026-05-17-feed-tabs-design.md)

**Spec deviation noted:** Spec proposed `feed.tabs.*` i18n keys. Implementation reuses the existing `feed.news`, `feed.videos`, `feed.saved` keys (they already exist in all 5 locales) and only adds `feed.originals` + `feed.empty.*`. Reduces i18n diff.

**Files:**

Create `src/app/[locale]/(app)/feed/FeedTabs.tsx` with:

```tsx
// src/app/[locale]/(app)/feed/FeedTabs.tsx
'use client'

import { useTranslations } from 'next-intl'

// Tab union is duplicated here intentionally — FeedTabs is self-contained
// and doesn't import from its parent. FeedClient's local `FeedTab` type has
// the same shape; TS accepts structural matching across the prop boundary.
type FeedTabId = 'news' | 'videos' | 'originals' | 'saved'

const GREEN = '#7ED321'
const MUTED = '#6B7280'
const BG_BASE = '#1A1A1A'
const CHUNKY = 'polygon(3% 5%, 97% 0%, 100% 95%, 0% 100%)'

const TAB_ORDER: readonly FeedTabId[] = ['news', 'videos', 'originals', 'saved']

interface Props {
  active: FeedTabId
  onChange: (tab: FeedTabId) => void
}

export default function FeedTabs({ active, onChange }: Props) {
  const t = useTranslations('feed')
  return (
    <div
      style={{
        position: 'sticky',
        top: 0,
        zIndex: 10,
        background: BG_BASE,
        borderBottom: '1px solid rgba(255,255,255,0.06)',
        display: 'flex',
        gap: 6,
        overflowX: 'auto',
        padding: '10px 16px',
      }}
    >
      {TAB_ORDER.map(id => (
        <button
          key={id}
          type="button"
          onClick={() => onChange(id)}
          style={{
            fontSize: 10,
            fontWeight: 800,
            letterSpacing: 0.5,
            textTransform: 'uppercase',
            background: active === id ? GREEN : '#1A1A1A',
            color: active === id ? '#0a0a0a' : MUTED,
            padding: '8px 14px',
            cursor: 'pointer',
            border: 0,
            flexShrink: 0,
            clipPath: CHUNKY,
            fontFamily: 'inherit',
          }}
        >
          {t(id)}
        </button>
      ))}
    </div>
  )
}
```
