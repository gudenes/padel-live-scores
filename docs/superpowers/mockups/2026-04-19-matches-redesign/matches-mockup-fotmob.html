What's carried over from FotMob

  • Full-width date strip with "Today" prominent and underlined in green (was a small micro-strip before)
  • Tournament as a distinct card, not a flat section header — each card has its own chunky-polygon outline
  • Status pill on the LEFT (FT / LIVE / 18:00) — left-aligned state, right-aligned scores, so your eye scans consistently
  • Inline collapse chevron so you can hide tournaments you don't care about
  • Clock + Search + Calendar icons top-right as in FotMob (favourites count badge reused)

Padel-specific adaptations

  • Score is set-by-set columns (like tennis scoreboards), not a single goal count — current set highlighted in green
  • Player country flags inline before each pair name, since padel is international
  • Gender accent bar (blue men / purple women) kept on the left — preserves your existing visual language
  • Tournament-level badge on the right (P1, P2, Major, Gold) colored by tier

Differences from the previous mockup

  • Date strip is bigger and horizontally scrollable with named anchors ("Today", "Yesterday", "Tomorrow") mixed with dates
  • Each tournament is now a rounded-container card, not just a header row
  • Status moved from right → left; scores moved to far right
  • Added country flags next to player pairs
  • Removed the stand-alone summary pills and hero card — going minimal like FotMob

Take a look and let me know what to push further — list density, date strip, card containment, flag/colour tweaks, or if this direction feels right as-is.
