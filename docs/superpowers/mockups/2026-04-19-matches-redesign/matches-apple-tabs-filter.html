Bottom sheet slides up from the icon. Circuit + Gender = multi-select pills; Level = multi-select; toggles for favourites-only and hide-qualifiers. Footer has Reset (ghost) and Apply (brand green) with a live count of how many filters will apply.

Why a sheet, not a dropdown

  • Thumb reach. Bottom sheet puts Apply/Reset exactly where the thumb lives on a 6"+ screen.
  • Room to grow. Today you want Circuit + Gender + Level + toggles; tomorrow we'll add Country, Seed, Round, Court. A sheet absorbs new sections without crowding the tabs row.
  • Clear modal dismiss. Tap outside, swipe down, or hit Reset/Apply — unambiguous exit paths vs. a dropdown that can feel "how do I close this."

States the icon carries

  • Neutral — no filters applied. Icon sits in var(--bg-3) with muted color.
  • Active — ≥1 filter applied. Icon fills with --green-dim, turns green, and gets a "N" badge in chunky-polygon style.
  • Active-filter chip strip — optional thin row under the tabs showing each active filter as a removable chip, plus one-tap Clear. Can be suppressed if the user prefers cleaner chrome (config).

Everything the existing page already ships with

  • genderFilter ('all' | 'men' | 'women') — already there, rewire into the sheet
  • leagueFilter ('premier' | 'fip' | 'all') — already there, rewire into the sheet (now multi-select)
  • New state only for: level multi-select, favourites-only toggle, hide-qualifiers toggle
  • No new data fetches — all filters are client-side predicates on the already-loaded match arrays
