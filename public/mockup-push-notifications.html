Implementation

Avatar sourceFollow: player.avatar_url from Supabase Storage (already hosted) · Bookmark: 2 static circuit logos shipped with the app.
FCM payloadData-only message + custom FirebaseMessagingService on Android that downloads the URL and sets it as the notification's largeIcon.
Web pushNative icon field in NotificationOptions. Same URL.
iOSNotification Service Extension that downloads the URL and attaches it.
Failure modeIf the URL fails to load, notification still renders with text only — never blocks delivery.
