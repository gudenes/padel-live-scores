What changed structurally

  • Every chunky clip-path polygon replaced with border-radius. Pills → 999px. Cards → 16px. Icon buttons → 12px. Logo tiles → 12px.
  • Active date = a solid lime-green pill, not an underline. Stronger "you are here" signal.
  • Status on match rows is a rounded pill (LIVE / Final) instead of a polygon badge.
  • Current-set score gets a lime-green chip so the live set pops visually.
  • Tournament logo corner marker = a round dot (green for Premier, gold for FIP).
  • Icon buttons in the top bar are now soft-rounded square buttons that look at home next to the Apple Sports / Linear aesthetic.

Theme foundation

  • Every colour reads from a CSS variable (--bg, --surface, --brand, --accent, …). Nothing is hard-coded.
  • Theme switch = toggle a class (theme-dark / theme-light) on <html>, which production can bind to a user preference + prefers-color-scheme.
  • Light mode uses darker brand (#6FB816) and accent (#E09414) for AA contrast on white — not just "invert the dark palette."
  • Gender colours (men / women) map to both modes so accent bars stay legible regardless of background.

Lime & gold — where they show up

  • Lime: active date, "All" filter, Premier Padel circuit, P1 badge, current-set chip, favourites count badge
  • Gold: FIP Tour circuit, Gold-tier badge, the "NACHOS" in the logo
  • Neither colour is used for body text or large surfaces — they stay as accent-only, which keeps them punchy.

Dark and light previews are side by side on screen, plus full token palettes at the bottom. Tell me what to adjust — lime shade (brighter? more neon?), how much gold to sprinkle, corner radii, or anything else.
