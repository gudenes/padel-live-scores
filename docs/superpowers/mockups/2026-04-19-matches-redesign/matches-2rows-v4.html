v4 changes

  • Live match — vertical divider. The right side of a live row is now a 4-column grid: [set label] [set scores] [1px divider] [live points]. The 1px hairline sits at rgba(255,255,255,0.18), full row height. Clearly separates the "historical" set scores from the throbbing live point score.
  • Stacked "2nd set" label. Two lines: 2nd (12px / 900) + set (9px / 700 uppercase 0.85 opacity), both in live red, centered. Saves horizontal space and reads like a proper tennis-scoreboard tag. Mapping: 1st → "1st set", 2nd → "2nd set", 3rd → "3rd set".
  • Upcoming rows — bookmark + notify. A small vertical action cluster sits left of the time: a star (yellow/gold when active) and a bell (brand green when notifications are on). Tapping the star bookmarks; tapping the bell subscribes to match-start / score-update alerts. Both use the chunky-polygon clip for consistency.
  • Finished rows get a tiny "Final" label above the set scores (instead of an inline FT pill). Quieter.
