What changes on the existing Matches page

  • Replace the three tabs. Current: Live / Upcoming / Results → new: Yesterday / Today / Upcoming. Same underlined-active-tab pattern you already use, same swipe-to-change-tab behavior.
  • Today = live-first. A small Live Now · N strip sits above the tournament list. Tournaments that currently have live matches appear first (this is already how groupByTournament sorts — it stays as-is). Scheduled-today tournaments follow.
  • Yesterday = results scoped to one day. The current Results tab fetches everything in the year — for the Yesterday tab we tighten the query to finished_at >= yesterday-start AND < today-start.
  • Upcoming = date-grouped. Apple Sports' "Sun, 20 Apr ▴" date header shows above each day's matches. Tournaments nest inside the date header.
  • Nothing else changes. Chunky polygons, gender accent bars, tournament headers with the green top rule, match rows, score columns, Men/Women/Premier/FIP sub-filter — all untouched.

Data already in place — low-friction build

  • status on matches → drives Today's Live vs Scheduled split
  • finished_at on matches → drives Yesterday's date range
  • scheduled_at on matches → drives Upcoming date grouping
  • groupByTournament already sorts live-first → reused unchanged
  • useSwipeTabs hook already there → relabel the three tabs and adjust the fetch boundaries, no new infrastructure needed
