Set winner — readability options

Today: set score sits in a dark pill with the winner's color used only on the text. Subtle — easy to miss when both sets go the same way. Five alternatives below, all on Brussels P2 SF (Coello/Tapia 7-5 6-2).

Option A · Solid winner-colored pill

Option B · Score + chunky underline

Option C · Faint tint behind winner's bars
A subtle vertical gradient on the winner's HALF of the chart for each set — barely visible color wash. The score pill stays current. Reads at a glance: "this whole half belongs to orange".

Option D · Tagged pill with set label
Bigger pill with two lines: tiny "SET 1" label on top, score below in winner color, plus a check ✓ next to the score. More information, more contrast, requires more vertical room.

Option E · Pill snaps to winner's half
The score pill physically moves up or down depending on who won — orange wins, pill sits in the top half; yellow wins, pill drops below center. Spatial cue, no extra ink. Works because position itself becomes the signal.
