Button-palette review · three directions

Senior-UX take on what's off in the current pills, then three alternative palettes grounded in how Apple Sports, DAZN, FotMob, SofaScore, and ESPN handle the same problem.

What's off in the current palette

1
Three different "active" languages. Date pill = solid lime. "All" pill = solid white. Live pill = red-tint background. The user can't predict what "selected" looks like because the answer changes per control.
2
Brand colour under-used. Lime only shows up on one control (active date). The product's identity doesn't carry through to the rest of the chrome — a brand should feel present, not hidden.
3
Favourites has no colour identity. It's a default-grey pill with a star icon. Favouriting is a signature interaction for a scores app — it deserves its own visual treatment, the way Apple uses yellow, FotMob uses amber, ESPN uses heart-red.
4
White-on-black active state reads "system" not "brand." It works, but it feels like an iOS default, not PadelNachos. Putting lime on the active state owns the moment.

A · Monochrome + signal

Inspired by DAZN · Apple Sports
Strengths

Brand lime owns the single "active" state across every control on the page. Inactive pills are uniformly neutral so the active one pops. Live = quiet outlined red (not a fill) — present, not shouty.

Trade-offs

Favourites, Men, Women, Finished, Upcoming all look identical when inactive — no colour hint at what they mean. Fine if you value restraint, thin if you want instant glance-recognition.

DAZN · electric yellow as the only accent Apple Sports · tonal neutrals + single sport-tint Linear · near-monochrome UI

B · Tonal tints

Inspired by Apple Sports · iOS 17 controls
Strengths

Every semantically-charged pill has its own quiet tint even when inactive — Live=red, Favs=gold, Men=blue, Women=purple. Recognition is instant. Re-uses your existing men-blue / women-purple gender system. Plays beautifully in light mode too.

Trade-offs

More colours on screen at once. Needs disciplined saturation control so it reads "tonal" and not "candy." One rule: tinted fills never exceed ~14% opacity; solid fills are reserved only for the "active" pill.

Apple Sports · tonal tinted buttons per sport iOS 17 tinted buttons · native pattern Linear · tinted status chips

C · Semantic roles

Inspired by FotMob · SofaScore · ESPN
Strengths

Three colours, three jobs: lime = primary selection, gold = favourites/rewards, red = live/urgent. Bold, confident, reads from across the room. Favourites gets real identity.

Trade-offs

Solid fills on Live and Favs are louder than the tonal approach — can feel busy if the row is wide. Best if we cap solid-filled pills to two, never more. Gender + status stay neutral.

FotMob · amber favourites, red live SofaScore · orange primary + red live ESPN · red fill on active items

My recommendation as the UX reviewer → Option B. It solves every issue in the diagnostic (brand presence, consistent active, favourites identity) without tipping into "loud." Tonal tints are the current generation of mobile-sports design language (Apple Sports, iOS 17, Linear) and they let you reuse the men-blue / women-purple gender palette you already own. Option C is the runner-up if the product voice is "confident and bold" rather than "calm and premium."
