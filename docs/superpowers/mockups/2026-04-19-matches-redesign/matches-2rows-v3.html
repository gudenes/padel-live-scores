What changed in v3

  • Mixed-case tournament names. NEWGIZA P2 2026 → Newgiza P2 2026; FIP SILVER NOLA → FIP Silver Nola. P1 / P2 / FIP stay uppercase because they're acronyms (the existing titleCase() helper's KEEP_UPPER set already handles this). Font bumped 14 → 15 px and letter-spacing tightened (-0.1px) because mixed-case doesn't need tracking.
  • Tournament is now a container. Each tournament gets its own chunky-polygon card (margin: 14px 12px 0, border: 1px solid rgba(255,255,255,0.10), clip-path: CHUNKY.card). A soft shadow (0 4px 12px rgba(0,0,0,0.25)) lifts it off the page. All match rows for that tournament live inside.
  • Header inside the card has a very subtle tint (rgba(255,255,255,0.02)) and a hairline bottom border — visually sets it apart from rows below without being a heavy dark block.
  • Match rows now sit on the card background (no explicit BG_CARD fill) so the whole tournament reads as one unit. Row-to-row separators use the same hairline border.
