My take

For a live-scores app where most users come to scan a feed, Option A wins: the summary line ("All · M+W · Live + Upcoming") is constantly informing the user what they're filtering, and a single tap fine-tunes. Option B looks great in screenshots but the FAB sits over content and you lose the running summary. Option C is fine if you have lots of confident users but newcomers often miss header icons.

If we wanted a hybrid, Option A on first visit + collapse to Option C after the user has used it a few times would be ideal — but probably not worth the engineering cost yet.
