Palette A — the rules we just locked in

  • Lime is the ONLY active state. Active date, active filter pill ("All"), current-set score chip, favourites count on the bell — all share one language.
  • Inactive pills are uniformly neutral. --surface background, --border outline, --text-sub text. Favs / Men / Women / Finished / Upcoming look identical until selected.
  • Live is outlined red, not filled. Both on the filter pill and on the match-row status pill. Pulsing dot + red text + thin red border. Present, never shouty.
  • P2 badge demoted to neutral. Since lime now means "active," it can't also mean "this is a P1." So P1 keeps the subtle lime tint (it's the top tier); P2 drops to neutral to keep hierarchy honest.
  • Gold stays as a sparing accent: "NACHOS" wordmark, FIP circuit badge, Gold-tier badge. Never competes with lime for attention.

What still reads the same

  • Scrollable 7-pill filter strip with right-edge fade hint
  • Country-flag tournament tiles with circuit corner-dot
  • Premier Padel → FIP Tour sort order
  • Today-centered date strip, lime active day
  • Men-blue / women-purple accent bar on every row
  • Theme tokens ready for dark ↔ light flip

If this locks, next pass: bottom nav (Matches · Tournaments · Rankings · Discover) in the same language, then a Discover stub, then the spec doc.
