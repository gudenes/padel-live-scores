Buttons — style reference

Canonical reference for every PressButton variant. Built on the production <PressButton> face/skirt mechanism (src/components/PressButton.tsx) — every variant here translates 1-to-1 to a real button you can ship. Click any button to feel the press.

How to use this reference. Each variant has an anchor ID — copy it from the TOC or the small #id labels under each example. When you want to replace a button, refer to it like:
"Replace the YouTube link with #lib-watch-yt from the mockup"
"Use #where-to-watch for the FIP stream affordance"
