v5 changes

  • Filter strip scrolls horizontally. Seven chips (All, Live, Favs, Men, Women, Finished, Upcoming) exceed one row → the strip becomes swipeable.
  • Soft fade on the right edge (CSS gradient matching the page --bg) so the user immediately perceives "there's more off-screen."
  • Smooth momentum scrolling (-webkit-overflow-scrolling: touch) + scroll-snap on pills so each chip settles neatly after a swipe.
  • Scrollbar hidden on all platforms; touch stays native, gesture-friendly.
  • Tournament tile = country flag. No more initials. Each card's left tile is a 40×40 rounded flag with the circuit corner-dot on top (lime for Premier, gold for FIP). In production, the flag pulls from tournament.country via your existing FlagImage component.
  • Dropped the duplicate inline flag beside the tournament name — it was redundant with the big left-side flag.

On screen: try swiping the filter row horizontally. Also note each tournament card now leads with its country flag. If this locks, next round we design the bottom nav (Matches · Tournaments · Rankings · Discover) + Discover landing stub in the same language.
