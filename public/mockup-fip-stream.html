Where to Watch — FIP YouTube

Mockup for FIP-tier match livestream surfaces. Tiered fallback so the user always lands somewhere useful, even when our discovery cron didn't pin down the exact court stream.

1. Match list — no extra row

Three integration approaches that signal stream availability without growing the card vertically. Each variant shown with LIVE + FINISHED states for direct comparison. Pick one.

Variant A · Court chip becomes the link

YouTube glyph prefix on the existing court chip. The chip itself becomes a tap target opening the stream. Strongest semantic match — stream IS per-court. Tap → opens YouTube directly. Tap anywhere else on the card → match detail.

My read: Variant A is the most semantically honest (stream is per-court, so the court chip should be the affordance) and lightest visually. Variant B has the strongest call-to-action but turns the LIVE chip into a button — could feel tappy on a card that's already tappable. Variant C now has the largest, most thumb-friendly tap target and clearest visual presence — the trade-off is it requires restructuring the existing pair-row flex layout in MatchCard.tsx, slightly more invasive.

3. Fallback chain — what each tier links to

Same UI component renders all four; copy and target URL degrade with whatever data we have. The user always lands somewhere useful.

  1. 1
    Match-level deep link — v2, future
    Manual ops timestamp inside the court VOD. Lands at exact match start. youtube.com/watch?v=ABC&t=6210s
  2. 2
    Court livestream / VOD
    Court → stream linked by title parsing. Live or replay URL for the right court. youtube.com/watch?v=ABC
  3. 3
    Tournament channel filter
    No court linked, but tournament has a known channel. Scoped search URL. youtube.com/@fip/search?q=Mendoza
  4. 4
    Generic FIP channel
    Last resort. Always works for FIP-tier matches. youtube.com/c/fipinternationalpadelfederation

4. What's NOT included in v1

Inline YouTube embed. Aggregators don't embed third-party players (only rights-holders do). Always deep-link out.

Automatic match-start timestamps. Pre-roll variance + court turnover gaps make naive math wrong by 10–30 min. Manual ops timestamps unlock Tier 1 later if the operator effort is worth it.

Per-match chapter scraping. FIP doesn't chapter VODs consistently and never with player names. Dead end.

Premier broadcasters. Already covered by the existing WhereToWatch component on tournament pages. This feature is FIP-tier only.
