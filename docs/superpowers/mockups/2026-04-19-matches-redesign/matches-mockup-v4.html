What changed in v4

  • All emojis removed. Top-bar icons (Search / Star / Calendar) and the row chevron are inline SVGs — single-colour, stroked, currentColor-driven so they theme automatically.
  • Filter pills extended. All / Live / Favs now use flex: 1 1 0 and stretch to fill the row equally. Also got bigger (13px · 10px padding) so they read as real buttons, plus a small count badge inside (All 23 · Live 3).
  • The Favs pill now has a leading star icon so it's recognisable without typing it out in full.

Browser is refreshed. Tell me if the filter pill proportions feel right, or if we should push further (bigger, taller, different label wording, different active state).
